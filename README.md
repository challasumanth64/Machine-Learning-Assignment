# Machine-Learning-Assignment
This project focuses on analyzing key molecular properties of drug-like compounds using a dataset sourced from the PubChem database. The dataset includes information such as Molecular Weight, XLogP (a measure of lipophilicity), InChIKey, and Canonical SMILES for compounds like Aspirin, Paracetamol, and Ethanol. Using Python libraries like Pandas, Matplotlib, and Seaborn, the data was loaded, cleaned, and visually analyzed to explore meaningful property relationships such as Molecular Weight vs LogP and LogP variation across compounds.

The visualizations help in understanding how molecular characteristics influence drug design and formulation decisions. For example, properties like Molecular Weight and LogP are crucial for predicting solubility, permeability, and solvent compatibility—factors that significantly impact drug bioavailability and effectiveness. This analysis can aid in rational solvent selection and early-stage drug screening processes.
